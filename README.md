# CyberShield Pro - Modern Cybersecurity Landing Page

A high-conversion landing page for an elite cybersecurity pentesting firm built with React, Tailwind CSS, and Framer Motion.

## Features

### Visual Design
- **Dark Theme**: Deep midnight-black background with subtle radial gradients
- **Interactive Cursor Effect**: Flashlight/gradient glow that follows the cursor
- **Particle System**: Animated digital mist effect in the background
- **Glassmorphism Cards**: Modern, translucent card design with hover effects

### Sections
1. **Navbar**: Sticky navigation with mobile responsiveness
2. **Hero Section**: Bold typography with glitch-style animations
3. **Services Grid**: 5 interactive service cards with hover-tilt effects
4. **Process Timeline**: Vertical animated timeline showing methodology
5. **Benefits Section**: 3-column grid highlighting key advantages
6. **FAQ Accordion**: Expandable Q&A section with smooth animations
7. **Articles Preview**: Blog post grid with image placeholders
8. **Footer**: Complete footer with newsletter signup

### Technical Stack
- **React 18.3.1**: UI framework
- **TypeScript**: Type safety
- **Framer Motion**: Advanced animations and transitions
- **Tailwind CSS**: Utility-first styling
- **Lucide React**: High-quality icons
- **React Intersection Observer**: Scroll-triggered animations

### Animations
- Scroll-triggered reveal animations on all sections
- Smooth hover transitions on buttons and cards
- Floating particle effects
- Cursor-following glow gradient
- Staggered entrance animations

## Customization

### Colors
Update the theme colors in `tailwind.config.js`:
- `cyan-glow`: Primary accent color
- `purple-glow`: Secondary accent color
- `dark-bg`: Background color
- `dark-card`: Card background color

### Typography
Font family set to 'Inter' and 'Sora' via Google Fonts in `index.html`

### Content
All static content is defined within component files for easy updates.
